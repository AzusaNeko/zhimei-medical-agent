## 1. 产品上下文

**产品**：智美医美顾问 —— 面向医美顾客的 AI 在线咨询系统。
**技术内核**：LangGraph 多 Agent 图（主图 + 知识科普子图 + 风险审查子图 + 有界修订回路 + 放行凭据校验）。

**它解决什么（JTBD）**：

| 顾客想做的事 | 系统怎么接 |
|---|---|
| 问清一个项目的原理、恢复期、风险 | 知识科普子图检索 + 逐句核对引用是否可溯源，然后作答 |
| 判断自己适合不适合、要不要到店 | 高风险标签识别 → 三份审查意见 → 放行或转人工 |
| 办一件事（改约、取消、问价） | 槽位抽取 + 实名核验 → 生成方案 → **用户二次确认**才执行 |
| 出现紧急症状 | 紧急词表命中 → 急诊模板 + 并行转人工 |
| 想跟真人说话 | 连续要求 3 次才转，前两次安抚并整理摘要 |

**两个界面**：

1. **C 端聊天页** `/chat`（`Code/app/web/chat.html`）—— 顾客侧。三栏：历史对话 | 对话 | Agent 执行轨迹 + 工作流架构图。
2. **坐席工作台** `/ops/panel`（`Code/app/ops/panel.html`）—— 运营侧。工单队列 → 接单接管 → 回复 → 关单。

## 3. 功能不变量（"功能不变"的具体含义）

重设计只改变视觉呈现。以下必须 1:1 保留：

1. **所有 DOM id 与表单控件**：`#convList` `#messages` `#input` `#send` `#statusbar` `#takeoverBar`
   `#gSvg` `#nodes` `#authLayer` `#formLogin` `#formReg` `#tabLogin` `#tabReg` `#traceOn` `#newChat` …
   （`scripts/check_ui.cjs` 有 69 项静态断言守着这些，改 id 就是改功能）
2. **四类消息气泡**：`user`（右，实心主色）/ `bot`（左，浅底描边）/ `sys`（居中，警示黄）/ `err`（居中，错误红）
3. **语义色不能被"美化"掉**：`ok` 绿 / `warn` 琥珀 / `bad` 红 三态必须一眼可辨，且**只用于语义**，不得当装饰色
4. **调试视图与顾客视图的分离**：`执行轨迹` 面板是**排障用**，展开内容含**未经审查的中间产物**。
   视觉上必须让它**明显区别于**对话正文区（顾客只应看对话区那份"已审正文"）
5. **"人工接管"提示条**：醒目但**不阻塞**输入框（用户仍可补充情况）
6. **打字机正文角标**：文案是「逐字呈现 · 整段过审后送达」
7. **工作流架构图**：六层分层（入口与调度 → 七路草稿产出 → 聚合与必经关卡 → 修订回路 → 输出与执行 → 出口层）；
   节点三态（未走 / 走过 / 正在走）、**菱形=路由点**、**走过的边有流动动画**、黄点=会调用大模型
8. **子图配色区分**：主图 / 知识科普子图 / 风险审查子图 三色体系
9. **三档断点**：`>1360px` 三栏 / `≤1360px` 隐藏轨迹栏 / `≤900px` 单栏
10. **`prefers-reduced-motion`**：所有动画必须可被关闭
11. **工作流架构与执行轨迹是两个独立的演示区域，左右排布**：各是一张独立卡片，
    各有自己的标题栏、工具条与滚动条。不得合并回一张卡，也不得做成一栏切换。
    宽屏（≥1440px）各占主栅格一栏；窄屏收回第三栏上下堆叠。
12. **所有弹窗一律自建**：不得使用原生 `alert` / `confirm` / `prompt`。
    原生弹窗样式不可定制、与整页视觉脱节，`confirm`/`alert` 还同步阻塞页面，
    `prompt` 只有单行输入、做不了必填校验（坐席"关闭原因"是必填的）。
    统一走 `window.dialogs` 的 Promise 版 `confirm / prompt / alert`。
13. **卡片宽度可由用户拖动调整**：栏与栏之间是一条可拖拽分隔条（占的就是栏间距本身），
    拖动改相邻两栏比例、**两栏总宽守恒**（不会把别的栏带歪），双击恢复默认，
    聚焦后 ← / → 也能调（Shift 加速）。宽度必须写进 CSS 变量并**用 `fr` 单位**，
    保证栅格始终填满容器、窗口缩放自动等比；窄屏堆叠模式下分隔条隐藏。
    宽度按页持久化到 `localStorage`（两页用不同的键）。

## 4. 基线令牌（BASELINE —— Step 3a 像素级复刻用）

Step 3a 的复刻草稿**必须**严格使用这套现值，不得使用第 5 节的新方向色板。

```css
:root{
  --ink:#19344a; --muted:#586d7b; --line:#d7e1e7; --accent:#226b62; --accent2:#1b554e;
  --bg:#f3f6f8; --card:#fff; --warn:#b3862a; --bad:#c8493a; --ok:#3f8a72;
  --g-main:#19344a; --g-kb:#2f5d8a; --g-risk:#9a5b2a;
}
body{ font:14px/1.7 "Microsoft YaHei","PingFang SC",-apple-system,sans-serif }
code,.mono{ font-family:Consolas,"SF Mono",Menlo,monospace }
```

- 卡片圆角 `12px`、按钮/输入 `8–9px`、胶囊 `999px`、气泡 `12px`（尖角侧 `3px`）
- 卡片：`1px solid var(--line)` + **无阴影**
- 布局：`grid-template-columns:236px minmax(360px,1fr) minmax(330px,.92fr)`，`gap:16px`，`max-width:1660px`
- 卡片高度：`calc(100vh - 132px)`，`min-height:560px`
- 浮层：`rgba(23,47,64,.45)` + `backdrop-filter:blur(3px)`，卡片阴影 `0 18px 60px rgba(12,30,42,.28)`

**现状诊断（新风格要解决的问题）**：navy+teal 的通用"企业后台"观感，与"医美"这个需要**信任与温度**的品类不匹配；
灰底白卡 + 全描边让整屏缺少层次；信息密度高但视觉主次不清；主色 `#226b62` 与 `ok` 绿 `#3f8a72` 过近，语义色不独立。

## 5. 新视觉方向（Step 3b 两个变体各取其一）

两个方向**共享**第 3 节全部功能不变量与第 6 节硬规则，仅在视觉语言上不同。
每个变体的 `-p` 必须**逐字列出**自己的完整令牌集合，并声明只用该集合。

### 方向 A —「临床白 · Clinical Precision」

**隐喻**：现代医疗级仪器的操作界面。精确、安静、无装饰、以可读性为唯一优先。
适合让顾客感到"这是专业医疗系统，不是美容院营销页"。

```css
:root{
  --ink:#0F1D2B; --ink-2:#33475A; --muted:#67788A; --line:#E4EAF0; --line-strong:#CBD6E0;
  --bg:#FAFBFC; --surface:#FFFFFF; --surface-2:#F4F7FA;
  --primary:#0B6E6E; --primary-hover:#095858; --primary-soft:#E6F2F1;
  --ok:#16794F; --warn:#9A6B12; --bad:#B3261E;
  --g-main:#0F1D2B; --g-kb:#1E4E7A; --g-risk:#8A4B1E;
}
```
- **字体**：正文 `"PingFang SC","Microsoft YaHei",-apple-system,"Segoe UI",sans-serif`，**基准 14px / line-height 1.65**；
  数据与 id 用 `"JetBrains Mono","SF Mono",Consolas,monospace`（11–11.5px，`letter-spacing:.2px`）
- **圆角**：卡片 `8px`、按钮/输入 `6px`、气泡 `10px`（尖角侧 `4px`）、胶囊 `999px`
- **描边优先，几乎不用阴影**：卡片 `1px solid var(--line)`，浮层才用 `0 16px 48px rgba(15,29,43,.18)`
- **主色与语义色严格分离**：`--primary` 只用于主操作与选中态；`--ok/--warn/--bad` 只表语义，绝不当装饰
- **层次靠留白与字重**，标题 `600`、正文 `400`，不用渐变色块
- **动效**：`120ms ease-out`，只有 opacity/transform；`prefers-reduced-motion` 下全部关闭
- **架构图**：细线 `1px`，节点直角化倾向（`3px` 圆角），层底色 `--surface-2`

### 方向 B —「暖瓷 · Warm Porcelain」

**隐喻**：高端医美诊所的接待空间。温润、松弛、有呼吸感，让顾客在读术后护理这类内容时感到被安抚。

```css
:root{
  --ink:#2A2320; --ink-2:#4A3F39; --muted:#7C6C63; --line:#EBE3DC; --line-strong:#D9CCC2;
  --bg:#FAF7F4; --surface:#FFFFFF; --surface-2:#F5EFE9;
  --primary:#9C5F4E; --primary-hover:#814C3E; --primary-soft:#F6EAE5;
  --ok:#4A7C59; --warn:#A87A1F; --bad:#B5473C;
  --g-main:#2A2320; --g-kb:#4A6B8A; --g-risk:#A05A32;
}
```
- **字体**：正文 `"PingFang SC","Microsoft YaHei",-apple-system,sans-serif`，**基准 15px / line-height 1.8**（比基线更透气）；
  标题可用 `"Songti SC","Noto Serif SC",serif` 增温；数据仍用等宽 `Consolas,"SF Mono",monospace`
- **圆角**：卡片 `16px`、按钮/输入 `10px`、气泡 `14px`（尖角侧 `6px`）、胶囊 `999px`
- **柔和层叠阴影**：卡片 `0 1px 2px rgba(42,35,32,.04), 0 8px 24px rgba(42,35,32,.06)`，**不用重描边**
- **主色 `--primary` 与语义色分离**：玫瑰陶土色只做品牌与主操作；语义三色独立且降饱和但仍可辨
- **动效**：`200ms cubic-bezier(.2,.7,.3,1)`，可含轻微上浮；`prefers-reduced-motion` 下全部关闭
- **架构图**：层底色用 `--surface-2` 暖灰，节点圆角 `6px`，连线 `1.25px`

## 6. 两个方向共享的硬规则（HARD RULES）

1. **只用本方向列出的令牌**。不得引入未列出的字体、颜色、阴影、渐变。
   （禁止：紫/粉渐变、霓虹色、装饰性 serif 标题混排、随机 emoji 图标）
2. **中文可读性优先**：正文行高 ≥1.65，单行 ≤ 42 个中文字符；数字/ID/耗时一律等宽字体以便纵向对齐。
3. **语义色只表语义**：`ok/warn/bad` 不得用于装饰；风险标签三态必须一眼可辨（不能只靠颜色，
   需同时有文字或形状区分 —— 色盲可用性）。
4. **调试区与顾客区的视觉分离**：执行轨迹面板必须有一眼可识别的"技术视图"标识（等宽字体、
   独立底色或左侧色条），与对话正文区在视觉上明确不同层级。
5. **对比度**：正文与背景对比度 ≥ 4.5:1；`--muted` 用于次要信息时 ≥ 4.5:1；大字/图形 ≥ 3:1。
6. **不改变任何布局尺寸契约**：三栏宽度、卡片高度、断点行为、浮层结构都保持第 2、3 节所述。
7. **不使用外部资源**：不得引用 CDN、外链字体、外链图标库（项目是"单文件 HTML + 无构建 + 无 CDN"，
   由 FastAPI 直接托管）。图标一律用内联 SVG 或 CSS 绘制。
8. **`prefers-reduced-motion: reduce`** 下关闭所有动画（流动边、脉冲、打字机光标、上浮）。
9. **不引入浏览器原生交互控件**：弹窗（`alert` / `confirm` / `prompt`）一律自建，
   正文用 `textContent` 渲染（不解析 HTML）。见第 3 节第 12 条。
10. **分隔条占用的就是栏间距本身**，不额外画常驻竖线（悬停/聚焦时才显提示线）；
    宽度用 `fr` 写进 CSS 变量，**绝不内联 `grid-template-columns`** ——
    内联样式优先级高于媒体查询，会把窄屏的堆叠布局永久钉死。
